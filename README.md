# 자커마스 (OCCM)
자커마스는 마스토돈 서버 "자커마스"를 가장 편하게 이용하기 위해 만들어진 전용 클라이언트 앱으로, 마스토돈 앱 **Moshidon**을 포크(Fork)하여 제작되었습니다.

■ 주요 기능
- **자체 DM 기능 연동**: 자커마스 서버의 전용 다이렉트 메시지 화면을 빠르게 오갈 수 있도록 다듬어졌습니다. 새 메시지 알림이 오면 화면을 새로고침하지 않아도 바로 반영되고, 대화 상대의 프로필과 커스텀 이모지도 매끄럽게 표시됩니다.
- **답장할 멘션(Pending Mentions) 연동**: 자커마스 서버 고유 기능인 '답장할 멘션' 기능과 완벽하게 연동되어, 확인해야 할 멘션들을 놓치지 않고 원활하게 소통할 수 있습니다.

# OCCM
occm is a dedicated Mastodon client built to make using the occm server as smooth as possible. This app is a fork of the Mastodon app **Moshidon**.

■ Key features:
- **Custom DM Integration**: Tuned specifically for the occm server's custom direct message features. The DM screen facilitates quick back-and-forth conversations where new messages show up right away without needing to refresh, and avatars and custom emojis render smoothly.
- **Pending Mentions Integration**: Fully integrated with occm's unique "pending mentions" feature, allowing you to easily track and manage replies so you never miss a conversation.
